I used a grid for the case study/submit inquiry section. Inside this grid I used another grid within the Lab Archive area to make the grey box in the bottom right. I created the grid by setting the columns and rows using the terms 'grid-cols-4 and grid-rows-4' I also used 'grid-span' to make the items take up a space in multiple columns and grids.

To make a theme, I used the @theme syntax in the input.css folder and set the custom themes as 'brand-gold' and 'deep-charcoal'. Once this is set, I can use the custom colours the same way as the default ones (e.g: text-brand-gold).
